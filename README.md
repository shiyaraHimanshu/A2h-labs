# A²H Labs — Website

One-page website for **A²H Labs**, an AI solutions company in Ahmedabad, Gujarat.

## Publish with GitHub Pages
1. Create a new repository (e.g. `a2hlabs`) and upload `index.html` to the root.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then **Save**.
4. After a minute the site is live at `https://<your-username>.github.io/<repo-name>/`.

## Custom domain (optional)
In **Settings → Pages → Custom domain**, enter your domain (e.g. `a2hlabs.com`) and add the DNS records GitHub shows you at your domain provider.

## Editing
Everything is in `index.html` — plain HTML, no build step. Accent colour is `#C6F432`; search and replace it to change the theme.
